# 00 · 愿景与 Demo 范围

## 1 一句话

**《拾遗井》**（暂定名，英文名待定并需重名检查）是一款低难度的短途卡牌远征。你是枣花镇老井的新任守绳人，顺着一根会说话的老麻绳下到井底的「遗落之境」，替镇上的人找回他们最惦记的东西。找到的「信物」这一趟可以借来用，回到井口必须物归原主，换来一段故事和一张永久的新牌。

> 每一趟下井，都知道自己是为谁下去的。

## 2 相对原方案「失物井」的调整

| 原方案 | 现在 | 理由 |
|---|---|---|
| 名字《失物井》、据点「失物招领处」 | 《拾遗井》、据点「守绳屋」 | 竞品 Lost and Found Co. 已占住"替镇民找回失物"的温馨印象。"拾遗"仍有捡回遗落之物的意思，但换了说法；据点也不再像柜台或店铺 |
| 没有旁白人物 | 井绳「麻爷」是会说话的百年老麻绳，担任旁白、教学和吐槽 | 炉石冒险模式靠旁白人物串起全程。麻爷就挂在牌桌上方，失败时的「收绳回家」也有了具体的画面 |
| 分岔路线是节点地图 | 「翻路牌」：每一段从 2 张扣着的路牌里选 1 张翻开；画面左侧是竖直的井道剖面，表示下到了多深 | 用户要求不要地图移动。翻牌本身就是卡牌游戏的语言，路线选择的信息量不变 |
| 借用—归还"不是两难" | 保留"必须归还"，另加可选的「心愿」：每件信物有一个小心愿，这一趟顺路完成，归还故事多一幕，复刻牌变成「＋」版 | 原方案里借用没有选择。心愿把路线选择和故事挂上钩，仍然没有惩罚 |
| 故事只在回到地面后讲 | 信物在战斗里会用主人的声音说话；首领、精英有台词；牌桌上有可以点的小彩蛋 | 炉石冒险式叙事：故事在对局中间讲，不只在关卡之间讲 |
| 6 层、主线 6–8 小时 | Demo 只做第 1 层「袜沼」 | 先验证核心玩法 |

核心玩法全部保留：回合制卡牌战斗（4 张手牌、3 点能量、攻击/守护/特殊三类牌、敌人意图公开）、短途远征、战后三选一的「奇物」改写规则、借用—归还换故事和永久新牌、温和的失败。

## 3 设计支柱【定】

1. **每件奖励都带故事**：信物有主人，归还会播放主人的故事并留下一张复刻牌；奇物也都是"别人丢的东西"，各带一句来历。
2. **奇物改写规则，不只加数值**：拿到一件奇物，打法就该变一下（例如"每回合第一张攻击牌打两次"），而不是"攻击 +1"。
3. **低难度、不折磨**：默认牌组就能打通普通流程；失败不会丢掉故事和永久进度；危险提前显示，能预览的结果先预览。
4. **故事在牌桌上讲**：插画页、对手登场、对局中的台词、牌桌彩蛋（见 [04-storytelling.md](design/04-storytelling.md)）。不做在地图上走来走去的探索。
5. **一趟要短**：一次下井 15–20 分钟，随时可以停。

## 4 目标体验

| 时刻 | 玩家应该感到 |
|---|---|
| 第一次翻路牌 | "这张写着'湿漉漉的脚步声'，那张飘来茶香……选哪个？" |
| 拿到第二、三件奇物 | "等等，这两个配在一起……"，打法开始变形 |
| 信物在战斗里说话 | 布偶「棉棉」大喊"它要咬你左边！"：会心一笑，觉得这东西真的有主人 |
| 顺路完成心愿 | "带婚戒去篝火边暖一暖"，绕一点路也愿意 |
| 首领战 | 千袜蛇不停分裂小袜子，"先打小的！"想明白之后打得很爽 |
| 归还 | 一页页插画讲完主人的故事，复刻牌落进牌册：被打动，然后想接下一个委托 |
| 失败 | 麻爷把你拽回井口，"信物我替你捎上来了"，不心疼，想再来一趟 |

基调：温暖、俏皮、带一点怀旧的伤感。全年龄，不血腥：敌人被打败时散成一堆东西、逃走或者睡着。

## 5 Demo 范围【定】

| 项 | 内容 |
|---|---|
| 层 | 只做第 1 层「袜沼」，含普通战、精英、事件、篝火、交换摊、首领千袜蛇 |
| 委托 | 3 个：麦婶的婚戒、豆丁的布偶棉棉、信伯的旧信，每个都有心愿和归还故事 |
| 一趟 | 7 段路牌，约 15–20 分钟 |
| 全程 | 3 趟左右，约 45–70 分钟；归还 3 件信物并打败千袜蛇一次即为 demo 通关 |
| 内容量【建议】 | 起始牌 10 张；奖励池 14 张牌 + 3 张复刻牌（各有＋版）；奇物 15 件；普通敌人 6 种；精英 1；首领 1；事件 6 个 |
| 永久成长 | 守绳屋随归还次数开放 2 项服务（见 [02-rules.md](design/02-rules.md)） |
| 平台 | macOS 本机运行（Godot 编辑器或导出包）。Web 导出可选 |
| 操作 | 鼠标为主（点击、拖拽），键盘快捷键为辅 |

**Demo 要回答的问题**（详见 [plan/playtest.md](plan/playtest.md)）：
1. 一趟 15–20 分钟，能不能感受到奇物带来的打法变化？
2. 信物会说话、心愿、归还故事，能不能让人在意"这是谁的东西"？
3. 第 2、3 趟还新鲜吗？
4. 低难度下，战斗还有没有思考的乐趣？

## 6 刻意不做【定】

原方案清单，原样保留：

- 删牌优化
- 天赋树
- 永久死亡
- 撤离赌博
- 商店经营与定价
- 背包格子管理

Demo 阶段额外不做：

- 卡牌升级（复刻牌的「＋」版是心愿奖励，不是升级系统）
- 第 2 层及以后的内容（只放一页上锁的预告）
- 多存档槽、成就、设置之外的菜单
- 联网、内购、广告

## 7 术语（玩家可见，最多 5 个）【定】

| 术语 | 含义 |
|---|---|
| 能量 | 每回合 3 点，出牌消耗 |
| 守护 | 先替你挡伤害，你的回合开始时清零 |
| 意图 | 敌人下回合要做什么，头顶公开显示 |
| 奇物 | 战斗后拿到的小东西，拿到就生效，改写一条规则 |
| 信物 | 委托人惦记的那件东西，这一趟借来用，回去必须还 |

其它说法（例如"心愿""复刻牌""路牌"）只在出现时用一句话解释，不当作需要记的术语。
