# 05 · 界面流程

## 1 画面规格【建议】

| 项 | 规定 |
|---|---|
| 逻辑分辨率 | **640×360**，整数倍放大（1280×720 为 2 倍，1920×1080 为 3 倍），最近邻采样，多余部分黑边 |
| 字体 | Fusion Pixel 12px；大标题用 24px（整数倍放大） |
| 面板 | 九宫格边框，不透明底色，不用渐变 |
| 操作 | 鼠标为主：左键点击/拖拽，右键取消。键盘快捷键为辅 |
| 文字 | 所有文字来自内容文件，不画进图片 |

## 2 画面流程

```text
启动 → 标题 → 守绳手账（冒险书）
                 └→ 守绳屋（据点）
                      ├→ 委托板 → 委托卡详情（接 / 不接）
                      ├→ 牌册
                      └→ 井口：出发准备 →（出发选物）
                             → 路牌画面 ⇄ 节点（战斗 / 事件 / 篝火 / 交换摊）
                             → 首领 → 回到井口插画
                             → 归还插画页（逐件）→ 守绳屋
暂停菜单（任意时刻 Esc）：继续 / 设置 / 收绳回家（只在路牌画面可用）/ 回到标题
```

## 3 各画面布局

### 3.1 守绳屋

```text
┌──────────────────────────────────────────────────────────────┐
│  麻爷（盘在辘轳上）            墙：绳结 + 纪念画框（随归还增加） │
│                                                              │
│   [委托板]        阿穗（待机）          [牌册]      [井口→]   │
│                                                              │
│  门口：委托人小人（有新委托时出现，头顶"！"）                   │
└──────────────────────────────────────────────────────────────┘
```

- 场景是一张静态侧视插画（不是可行走地图），可点的东西悬停时描边高亮。
- 点委托人或委托板 → 委托卡（大卡片：委托人头像、一句话、要找的东西、心愿提示"？？？"）→「接下」。
- 点井口 → 出发准备面板：已接委托（1–2 张卡）+ 出发选物（如果开放）+「下井」。

### 3.2 路牌画面

```text
┌──────────────────────────────────────────────────────────────┐
│┌──┐                                                          │
││井│  第 3 段 / 7                                              │
││道│        ┌────────┐        ┌────────┐                      │
││剖│        │ (图标)  │        │ (图标)✦│                      │
││面│        │        │        │        │                      │
││  │        │提示语  │        │提示语  │                      │
││阿│        └────────┘        └────────┘                      │
││穗│                                                          │
│└──┘  生命 32/40   奇物栏 ○○○○      信物栏 ◇◇     [收绳回家] │
└──────────────────────────────────────────────────────────────┘
```

- 左侧竖条是井道剖面：7 格，已走过的格子显示走过的节点图标，阿穗挂在绳上表示当前深度。
- 两张路牌约 96×128，悬停时上浮 4 像素并显示预览。
- 底部常驻：生命、奇物栏（悬停看说明）、信物栏、牌组按钮（查看当前牌组）。

### 3.3 战斗牌桌

```text
┌──────────────────────────────────────────────────────────────┐
│麻爷                 [意图]   [意图]   [意图]        规则牌▢  │
│ ╲                   敌人1    敌人2    敌人3          (首领)   │
│  绳头               ▬▬▬▬     ▬▬▬▬     ▬▬▬▬                   │
│                     生命/守护                                │
│    牌桌背景（袜沼场景，带可点装饰）                             │
│                                                              │
│奇物栏 ○○○○○                                     信物 ◇◇     │
│┌────┐                                                        │
││阿穗│ 将受到 7    [牌][牌][牌][牌]          能量 ●●○  [结束] │
│└────┘ 生命 守护                              牌库12  弃牌3    │
└──────────────────────────────────────────────────────────────┘
```

- 敌人站在牌桌上半部分，侧视，最多 4 个横向排开。
- 手牌小卡 **56×76**：费用、名字、类型色边、小图。悬停时在上方放大成 **112×152** 的大卡，显示完整效果文字。
- 出牌：拖拽。拖动需要目标的牌时出现一根绳子形状的指示线，指向的敌人描边高亮，并显示预览数字（敌人头上"守护 4→0，生命 12→10"）。
- "将受到 X"常驻在阿穗头像旁：红字显示扣血量，挡住全部时显示绿色"挡住了"。
- 结束回合按钮在能量用完、或者手里没有能打的牌时轻轻发光。
- 敌人行动时逐个高亮，攻击动画 → 伤害数字从阿穗头像上弹出。

### 3.4 战后三选一

- 牌桌压暗，三张奖励牌并排落下（奇物以"奇物牌"形式展示：图标 + 名字 + 效果 + 来历）。
- 点一张 → 它飞进奇物栏或牌组；「跳过」在右下角。
- 牌组满 12 张时选了牌：弹出牌组网格，点一张替换出去，或者「取消」回到三选一。

### 3.5 事件

- 中央一张大事件牌（插画 160×90 + 描述），下方 2–4 个选项按钮，按钮文字直接写明结果。
- ♥ 选项用暖色边框。

### 3.6 归还

- 插画页序列（见 [04-storytelling.md](04-storytelling.md)），最后一页盖章。
- 盖章后显示一行小字：「复刻牌『誓约』已加入奖励池」。

## 4 操作一览

| 操作 | 鼠标 | 键盘 |
|---|---|---|
| 出牌 | 拖到目标 / 点牌再点目标 | 1–8 选牌，←→ 选目标，回车确认 |
| 取消选中 | 右键 / 拖回手牌区 | Esc |
| 结束回合 | 点按钮 | E |
| 看牌库/弃牌堆 | 点计数 | D / F |
| 翻页、跳过台词 | 点击 | 空格 / 回车 |
| 暂停 | — | Esc |

## 5 反馈与可读性【定】

- 每次操作都有声音和动画反馈（悬停、拿起、放下、无效操作）。
- 伤害、守护、回复数字用描边像素大字弹出：伤害红、守护蓝、回复绿。
- 意图图标形状不同（不只靠颜色区分），色弱也能看清。
- 所有效果文字一句话；悬停任何图标都有说明。
- 设置：主音量、音乐、音效、文字速度（慢/中/快/立即）、窗口倍数、全屏。

## 6 调试功能（只在调试版）

- F1 调试面板：显示种子；跳到指定段；直接给某件奇物、某张牌、某件信物；敌人生命设为 1；自动出牌（调用自动试玩策略）。
- F2 切换"所有台词立即显示"，方便检查文字溢出。
