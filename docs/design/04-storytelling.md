# 04 · 牌桌上的叙事（炉石冒险式）

【定】**不做在地图上走来走去的探索。** 故事全部在"冒险书 + 插画页 + 牌桌"上讲：章节像翻书，关卡之间放插画页，对局中途角色会说话，牌桌本身就是一幅可以点的场景。

参考的是《炉石传说》冒险模式的**表现手法**：旁白人物、插画分镜页、对手登场、对局中的台词、可以点的牌桌装饰。只学手法，不复刻它的界面图形、名字和文本。

## 1 叙事组件总览

| 组件 | 在哪出现 | 做什么 |
|---|---|---|
| 守绳手账（冒险书） | 标题之后 | 姑姑留下的手账就是章节选择：第一层「袜沼」可进，第二层「伞林」上锁，锁着的那页有姑姑的笔迹预告 |
| 插画页 | 开场、归还、结尾、收绳 | 一页一幅像素插画 + 1–2 行旁白，点击翻页 |
| 守绳屋小场景 | 据点 | 麻爷闲聊；委托人在门口出现，递上委托卡 |
| 对手登场 | 精英、首领战开始 | 大头像滑入、名号牌、对白一来一回，"规则牌"翻到桌上 |
| 牌桌台词 | 所有战斗 | 阿穗、麻爷、敌人、信物，按触发表冒出气泡 |
| 牌桌彩蛋 | 所有战斗 | 牌桌上 3–4 个可以点的装饰，点了有动画、声音，偶尔有台词 |
| 揭示与盖章 | 路牌、信物、复刻牌 | 翻牌、浮起、盖章这类有"手感"的小演出 |

## 2 插画页

### 2.1 规格【建议】

- 画面：书页边框里放一幅 **320×180** 的插画，下方是旁白框（每页最多 2 行、50 字）。
- 插画由**图层拼成**，方便复用素材：背景层 + 人物大立绘层 + 道具层 + 前景层。每层可以有 2–4 帧的小循环（蒸汽、火光、眨眼），也可以做整数像素的慢速平移。
- 点击、空格、回车翻页；右上角"跳过"一次跳过整段。翻页有纸张音效。
- 旁白说话人：默认是"旁白"（没有头像，文字居中）；也可以指定角色，此时左侧出现小头像和逐字说话音。

### 2.2 数据格式【建议】

`content/story/pages.json`：

```json
{
  "id": "story.return.ring",
  "pages": [
    {
      "layers": [
        { "art": "still.bakery_door", "x": 0, "y": 0 },
        { "art": "big.mai_aunt", "x": 180, "y": 40, "anim": "idle" },
        { "art": "prop.ring_glow", "x": 120, "y": 90, "anim": "sparkle" }
      ],
      "speaker": "npc.mai_aunt",
      "text": "就是它……就是它！"
    }
  ],
  "end": { "stamp": "card.vow" }
}
```

`when` 字段可以给单页加条件，例如 `{"wish": "keepsake.ring"}` 表示心愿完成才显示这页。

## 3 对手登场

精英和首领战开始时播放，约 4 秒，可以点击跳过（第二次遇到默认缩短为 1.5 秒）：

1. 牌桌压暗，对手大头像（96×96）从右侧滑入，左下角是阿穗的头像。
2. 名号牌落下：「千袜蛇 · 第九百九十九只」。
3. 对手说一句，阿穗回一句（气泡）。
4. 一张**规则牌**翻到桌面中央：用一句话写清这个对手唯一突出的机制（"凑对：每回合分裂出 1 条小袜子……"），停留 1 秒后缩到对手头像旁边，悬停可再看。
5. 恢复亮度，开始第一回合。

| 对手 | 登场台词 | 阿穗回应 |
|---|---|---|
| 饿抽屉 | 「……（嚼嚼嚼）」 | 「它是不是吃了什么亮晶晶的？」 |
| 千袜蛇 | 「九百九十七、九百九十八……嗯？你脚上那双，借我一只？」 | 「不借！」 |

## 4 牌桌台词

### 4.1 规则【建议】

- 说话人：**阿穗**（左下头像）、**麻爷**（从左上角垂下来的绳头）、**敌人**（头顶）、**信物**（信物栏图标）。
- 气泡**不挡操作**，显示时长 = 2.5 秒 + 每字 0.08 秒；同一个说话人同时只有一个气泡。
- 普通台词有 4 秒全局冷却，避免话太密；"优先"台词（教学、首领阶段转换）无视冷却，可以短暂锁住输入（最多 1.5 秒）。
- 每条触发可设：`once`（每场战斗 / 每趟 / 整个存档一次）、`chance`（触发概率）、`when`（附加条件）。
- 有逐字说话音（每个说话人一种音色，见音频方向），不做配音。

### 4.2 触发事件表

`content/story/banter.json` 里每条记录：`{ id, event, speaker, when, lines[], once, chance, priority }`。规则层只负责发出事件，台词调度器（`scripts/story/`）决定说不说、谁来说。

| event | 说明 |
|---|---|
| battle_start | 战斗开始（登场演出之后） |
| turn_start | 你的回合开始，带回合数 |
| card_played | 打出牌，带牌 id 和类型 |
| big_hit | 单次造成 12 点以上伤害 |
| perfect_block | 敌人回合结束时你没有掉血 |
| player_low_hp | 你的生命第一次低于 30% |
| enemy_defeated | 一个敌人被打败，带敌人 id |
| enemy_low_hp | 敌人生命第一次低于 30% |
| boss_phase | 首领进入阶段二 |
| boss_summon | 首领召唤 |
| relic_trigger | 某件奇物生效，带奇物 id |
| keepsake_get | 拿到信物 |
| wish_done | 心愿完成 |
| idle | 你 20 秒没有操作 |
| victory / defeat / retry | 胜利 / 战败 / 选择再打一次 |
| path_pick | 选了某类路牌 |
| hub_enter | 进入守绳屋，带"上一趟怎么结束的" |

## 5 牌桌彩蛋

每张牌桌有 3–4 个可以点的装饰。点击给即时反馈（动画 + 音效），连点有升级反应。不影响战斗结果，纯粹好玩。

| 牌桌 | 装饰 | 点 1 次 | 连点反应 |
|---|---|---|---|
| 袜沼 | 晾衣绳 | 一排袜子荡起来 | 第 5 次：一只袜子掉下来，「放我下来！」 |
| 袜沼 | 靴子里的青蛙 | 呱 | 第 3 次：跳进另一只靴子 |
| 袜沼 | 泡泡池 | 冒一个泡 | 每次都"啵"，第 10 次冒出一个特别大的 |
| 袜沼 | 芦苇丛 | 沙沙晃 | 第 7 次：芦苇杆上露出一个小小的"禾"字，麻爷：「……嗯？」（整个存档只说一次） |
| 千袜蛇巢 | 袜子山 | 塌下来一小块 | 第 5 次：雪崩，所有敌人头上冒出"？" |
| 千袜蛇巢 | 线团 | 滚一下 | 第 3 次：滚到麻爷那里，麻爷：「别拿我跟它比！」 |

## 6 揭示与盖章

| 演出 | 时长 | 过程 |
|---|---|---|
| 翻路牌 | 0.4 秒 | 牌翻面 → 井道剖面里阿穗下降一格 → 画面向下滚到下一段 |
| 拿到信物 | 约 3 秒 | 牌桌压暗 → 东西从敌人或事件里浮起、闪光 → 主人的半透明大头像（虚影色板）在背后淡入 → 一句主人的回忆台词 → 一张"信物牌"展开（名字、借用效果、心愿）→ 飞进信物栏 |
| 心愿完成 | 1.5 秒 | 信物图标亮起，♥ 跳一下，信物说一句话 |
| 复刻牌盖章 | 1.5 秒 | 归还插画最后一页，复刻牌从上方落下，"咚"地盖进牌册，旁边写"来自：麦婶的婚戒" |
| 首领预告 | 1 秒 | 横幅从上方落下，"两回合后：大缠绕 16"，之后缩成对手头像旁的倒计时小牌 |
| 第一次打败千袜蛇 | 约 3 秒 | 蛇身散成满地袜子，袜子两两配对蹦走；泥地里露出拴着绳结的芦苇，阿穗捡起来："这是什么结？"麻爷不说话（只在整个存档第一次播放） |
