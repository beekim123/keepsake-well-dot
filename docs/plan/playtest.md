# 试玩验证计划

Demo 的目的就是回答下面这些问题。每个问题都有：怎么测、合格线、不合格时先改什么。合格线是初稿，用户可以改。

## 1 自动模拟的目标区间（D1 起每次改数值都要跑）

| 指标 | 目标 |
|---|---|
| 普通战胜率（默认牌组 + 机器人） | ≥ 95%，平均 3–5 回合 |
| 精英胜率 | ≥ 85%，平均 5–7 回合 |
| 首领胜率：随机拿奖励 | 50–70% |
| 首领胜率：按倾向拿奖励 | 75–90% |
| 首领重试一次后的胜率 | ≥ 85% |
| 一趟估算时长 | 15–20 分钟 |
| 单件奇物对首领胜率的提升 | 不超过 +25%（过强），不低于 0（没用） |

## 2 用户试玩要回答的问题

### Q1 一趟里，能不能感受到奇物带来的打法变化？

- 观察：玩完一趟后请用户说出"哪件奇物让你换了打法"。
- 合格：能说出至少 1 件，并能描述变化（例如"拿了风筝之后我一直出守护牌"）。
- 不合格先改：奇物改成更极端的规则改写；三选一里保证至少一件和已有奇物同倾向。

### Q2 会不会在意"这是谁的东西"？

- 观察：看到 ♥ 路牌时有没有特意去走；归还插画页有没有跳过；玩完能不能说出 3 个委托人的名字。
- 合格：♥ 至少 2/3 次会去走；插画页跳过率低于 30%；能说出至少 2 个委托人。
- 不合格先改：信物台词更多、更贴近主人；归还故事更短更具体；心愿奖励更显眼。

### Q3 第 2、3 趟还新鲜吗？

- 观察：问"从第几趟开始觉得像在刷"。
- 合格：3 趟内没有"在刷"的感觉。
- 不合格先改：每趟开头加一件新东西（新事件、新敌人组合、麻爷新话题）；减少固定段。

### Q4 低难度下战斗还有思考吗？

- 观察：每回合平均思考时间；有没有"随便出完就结束"的回合；问"有没有哪一回合你想了很久"。
- 合格：大多数回合有一个"先出哪张"的小选择；用户能说出至少一个想了很久的时刻（通常是首领）。
- 不合格先改：敌人意图更多样（攻击/守护交替）；奇物带来更多条件判断。

### Q5 难度是否"不折磨"？

- 观察：战败次数，战败后选了什么，有没有抱怨。
- 合格：教学战 0 败；普通战基本不败；首领最多输 1–2 次；没有人因为失败不想继续。
- 不合格先改：敌人生命、首领召唤频率；重试削弱幅度。

### Q6 牌桌上的叙事有没有效果？

- 观察：有没有去点牌桌彩蛋；有没有对哪句台词笑出来；有没有嫌台词打扰。
- 合格：至少注意到一个彩蛋；没有"台词太多挡视线"的抱怨。
- 不合格先改：降低普通台词频率；气泡位置。

## 3 试玩后问卷（给用户）

1. 一共玩了多久？玩了几趟？
2. 哪件奇物让你印象最深？为什么？
3. 三个委托人里你最喜欢谁的故事？
4. 有没有特意去完成心愿？
5. 首领战输了几次？输的时候是什么感觉？
6. 从第几趟开始觉得重复？
7. 最想吐槽的一个地方？
8. 最想保留的一个地方？
9. 如果有第二层，你想不想继续玩？（1–5 分）
10. 整体好玩程度（1–5 分）
