# D1 平衡读数复核与后续取舍

当前保持低难度，不根据机器人的 100% 胜率直接加难度。这里只记录实际证据与候选改进，不改数值。

## 已有的真实选择

- 手套首次攻击重复、生日蜡烛首次牌放大，以及守护接拧干、誓约接守护，形成三点能量内的出牌顺序选择。
- 千袜蛇的小袜子提供守护和后续攻击，但吞袜时清空小袜子会将回血意图转为攻击 10，不能机械理解为永远先清小怪。实际预览应把变化说清楚。
- 口琴让剩余能量有价值，书签保留组合，纽扣奖励击倒顺序。
- 早拿 ✦ 可多借用几段并完成 ♥；错过会漂移但可能失去心愿，既保底又有路线差异。

## 不应误读的指标

- 两组远征都使用同一个防守型战斗机器人，只改变奖励倾向，不能叫作高手和新手两组。
- 偏好奖励总回合 2,326，随机奖励 2,948，前者少 21.1%，胜率相同不代表打法没有差异；路线和牌组也不同，不能归因到单一奇物。
- 当前机器人会在复制状态的出牌预览里读到实际新抽牌的身份，这比玩家界面可见信息更强。后续需要增加不读取未知抽牌身份的基线，而不是把现有胜率当成人群胜率。
- 随机合法动作探针允许提前结束回合，其低胜率不能代表普通新手。
- 奇物持有与未持有的胜率差是观察关联，当前两边都达到 100% 天花板；零差不代表奇物无效，也不是随机对照的因果效果。
- 第一次重试的条件胜率是 13/19；一次重试内累计通关是 44/50，不能混写。
- 300 趟内普通战均值 1.39–2.55 回合，低于 3–5 回合目标；部分敌人的第三拍特色可能来不及出现。先记录意图暴露/执行次数，再判断是否调顺序，不能仅凭均值说它们从未出现。

## 最小候选调整（尚未实施）

1. 增加公平信息机器人与意图暴露计数，把阅读、选择、战斗和调试中断计时分开。先修正测量，不改变游戏规则。
2. D2 让手套、蜡烛等已有触发显示“可用/本回合已用”，短促显示奇物生效，不增加系统或弹窗负担。
3. 第六段“晒绳”只加最大生命、不加当前生命；之后直接首领且目前无战斗治疗，因此首战几乎不获益。例外是最大生命可提高极低生命时重试的恢复底线。可比较“上限 +4 且当前 +4”与“回复 12”，但这会进一步降低首领难度，需对照测试并更新设计说明才采用。
4. 只有意图暴露测量确认问题时，才考虑把一个非教学敌人的既有特殊/守护拍提前；不全局堆生命、不插入等待来凑 15–20 分钟。

第一趟 542 秒是开发者操作与排错的墙钟时间，不是普通玩家时长。D2 的插画与动画也不能预先被当成自动补足时长的理由。最终是否有趣仍待完整试玩和用户反馈。
