# 需要用户拍板的问题

开发者遇到需要用户决定的事写在这里，**写明默认方案并按默认方案继续**。用户在"回答"一栏填写。

| # | 问题 | 默认方案 | 回答 |
|---|---|---|---|
| 1 | 英文名用什么？（需要做重名检查，避开 "Lost & Found"） | 暂用 `Keepsake Well` 作为工程名，不对外使用 | |
| 2 | 心愿没完成，是否允许以后补？ | Demo 只有一次机会，看试玩反馈再定 | |
| 3 | 主角阿穗能否改名、选外观？ | 不能，固定 | |
| 4 | 战败"再打一次"削弱敌人 20%，是否太宽松？ | 保留，低难度优先 | |
| 5 | 是否需要 Web 版给别人试玩？ | 只导出 macOS 版，Web 可选 | |
| 6 | 委托人的故事基调：现在偏温馨，是否需要更伤感一点？ | 温馨为主，每个故事带一点点遗憾 | |
