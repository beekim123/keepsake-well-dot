# 拾遗井 · 干净工程

这是基于 final352 独立工程制作的「绳与对」技术候选，工作分支为 `feat/rope-and-pair`。规则、教学和界面已更新；新 Dot 美术回收、真人试玩与用户正式验收状态见项目记录。不是安装包。

## 打开和运行

1. 使用 **Godot 4.7.2** 导入本目录的 `project.godot`。
2. 等待首次资源导入结束，然后按 **F5** 运行整个项目。

本轮建议先使用独立试玩入口，在项目根目录执行：

```sh
Godot.app/Contents/MacOS/Godot --path . --script tests/rope_pair/manual_playtest.gd -- --seed=147
```

这会重置调试存档 `user://d2-debug.json` 并停留交互标题，不自动打牌，不读写正式存档。普通编辑器 F5 使用正式存档；v1 首次迁移到 v2 时保留永久进度，将旧趟按收绳回家结束并归还已获信物，重新开始新玩法教学。

无需 Node.js、npm、原仓库、网络连接或额外下载素材。Godot 编辑器本身需另行安装；第一次打开时会生成 `.godot/` 缓存及 `*.import` 导入配置。

## 保留内容

- `scripts/`：游戏逻辑、存档、音频及界面代码，包含必要着色器。
- `scenes/`：当前游戏场景；入口为 `scenes/main.tscn`。
- `data/`：完整规则、卡牌、路线、剧情等运行数据。
- `resources/`：经过依赖审计的 233 张贴图、57 段音频、字体及完整字体许可证。仍被代码、场景、内容数据或必要回退路径引用的旧小图也保留，避免遗漏按需加载的依赖。
- `ASSET-NOTICES.md`：素材来源与许可说明。

在这个独立工程中可直接编辑代码、数据和素材，无需原仓库同步管线。本轮实现按敌人持久缠绳、双目标系绳与同类凑对、留牌补牌、免费抖牌、每场一次主动信物和凑对谢礼；剧情文件和既有人物台词保持不变。所有既有素材保留，新素材暂无回收，部分界面使用明确的程序占位。

`tests/` 已从历史恢复并加入新规则、迁移、三策略模拟、真实控制器和交互回归。入口见 [测试说明](tests/README.md)，三名新玩家的记录表见 [试玩说明](docs/qa/rope-playtest.md)。测试日志、数值快照、截图和 Dot 原图/任务记录均放 `.local/`，不提交。

自动测试与代理控制真实窗口不能代替真人体验和美术正式验收。本分支没有合并或推送；最终模拟实测、提交列表、未完成项和下一步见项目状态。

本轮验证范围和交接状态见 [`docs/v2/status.md`](docs/v2/status.md)。
