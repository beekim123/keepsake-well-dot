# 拾遗井（暂定名）

> 每一趟下井，都知道自己是为谁下去的。

低难度的短途卡牌远征，2D 像素风，用 Godot 4 制作。你是枣花镇老井的新任守绳人，顺着会说话的老麻绳「麻爷」下到井底，替镇上的人找回他们最惦记的东西。找到的信物这一趟可以借来用，回到井口必须物归原主，换回一段故事和一张永久新牌。

目标范围：第 1 层「袜沼」、3 个委托的核心玩法 demo。设计目标为约 45–70 分钟，当前尚未通过人工完整计时验证。

## 运行与检查

需要 Node.js 22.13+ 和 Godot 4.7.2。

```sh
npm ci
npm run sync
npm run dev
```

Node 工具不依赖第三方包。若 PATH 不是 Godot 4.7.2，请设置 `GODOT_BIN` 指向正确可执行文件，或把 macOS `Godot.app` 放在仓库根目录（不提交）。工具会验证真实版本，不静默使用旧版。也可以用 Godot 4.7.2 直接打开 `godot/project.godot`，资源副本已经生成。

```sh
npm run check
npm run art:sheet
```

D1 的完整远征模拟及原始报告见 D1 验证记录；不要把自动模拟时长当作真人游玩时长。首次点击才解锁音频；云端无音频设备的截图不代表实际听感通过。

## 灰盒操作

- 标题进入故事与手账，再到守绳屋接委托、准备下井。
- 路牌选一个落点；战斗点击/拖拽手牌，再选目标。数字键 1–8 选牌，方向键选目标，Enter 确认，E 结束回合；D/F 查看牌堆，Esc 返回/取消/暂停。
- 看敌人头顶意图及“将受到”预告；悬停/选牌可查看完整说明和出牌结果。
- 奖励三选一；满 12 张时选择替换或取消。失败可以再打，也可以收绳回家；信物仍按顺序归还。
- 三件信物归还且击败千袜蛇后出现 demo 结尾。随时暂停、退出后继续。
- `npm run shots` 是独立 QA 截图流程，须在可见桌面执行；压力场景明确标为 fixture，不覆盖正常存档。
