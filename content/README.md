# 内容源（D0）

只编辑此目录；`godot/data/` 由 `npm run sync` 生成。

- `registry.json` 登记源文件与相对目标路径。
- `data/cards.json` 是设计表里的四种起始牌定义，数量为 4 + 4 + 1 + 1。
- `data/ui.json` 是 D0 标题与手账预览文案。
- D0 卡牌 `art` 暂时引用**实际存在**的共享 `ui.panel.default`，不是独立卡面；D1 灰盒 / D2 正式卡面另行制作。
- D1 的敌人、奇物、信物、事件、路线、规则结算和完整远征均未完成；当前检查不冒充完整 Demo 内容验收。

`npm run content:check` 检查注册、稳定 id、重复项、路径、范围、当前基础效果文字一致性，以及可用美术/声音清单的引用。缺少清单时明确警告；同步与完整 `check` 则要求清单存在。添加新效果时同时扩展检查器与规则测试。
